# 🚀 Tejaswini Kadu — Developer Portfolio

A modern and interactive developer portfolio built with **React, Tailwind CSS, and GSAP**.

This project was created as part of a **Mini Hackathon challenge** where I independently learned GSAP and implemented animations and scroll-based interactions into a real-world project.

## 🌐 Live Demo

🔗 **Portfolio:** [https://portfolio-git-master-tejaswiniicodes-projects.vercel.app/]

## 📂 GitHub Repository

🔗 **GitHub:** [https://github.com/tejaswiniicodes/portfolio/]

---

## ✨ Features

- Modern and responsive portfolio design
- GSAP-powered animations
- Scroll-based animations using **ScrollTrigger**
- Smooth entrance animations
- Staggered text and element animations
- Horizontal project scrolling
- Interactive project showcase
- Responsive layout for desktop and mobile
- Clean component-based React architecture

---

## 🎨 GSAP Concepts Used

The main goal of this project was to learn and practically use GSAP.

Some of the concepts I explored and implemented include:

- `gsap.to()`
- `gsap.from()`
- GSAP Timelines
- Easing
- Stagger Animations
- `ScrollTrigger`
- Pinned sections
- Scroll-based animations
- Horizontal scrolling animations

I focused on using animations where they improve the overall user experience instead of adding animations unnecessarily.
